# HackerRank Solutions

Solutions to HackerRank problems.

Each solution is written to be readable rather than golfed: clear variable
names, an explicit approach, and the complexity noted where it isn't obvious.

## Java 

Solutions are grouped by problem domain:

- Introduction
- Strings
- BigNumber
- Data Structures
- Object Oriented Programming
- Exception Handling
- Advanced

Each file is self-contained and named after the problem it solves.

## Running a solution

```bash
javac Solution.java && java Solution < input.txt
```

Java 17 or later. No build system and no dependencies.

## Scope

Practice code, not a library. Problem statements and test cases belong to
HackerRank and are not reproduced here.
