## Java 
- Introduction
- Strings
- BigNumber
- Data Structures
- Object Oriented Programming
- Exception Handling
- Advanced

Each solution is written to be readable rather than golfed: clear variable
names, an explicit approach, and the complexity noted where it isn't obvious.

## Layout

Solutions are grouped by problem domain — introduction, strings, data
structures, object-oriented programming, exception handling, and algorithms.
Each file is self-contained and matches the problem name on HackerRank.

## Running a solution

Java:

```bash
javac Solution.java && java Solution < input.txt
```

Python:

```bash
python solution.py < input.txt
```
